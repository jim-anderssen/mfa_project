# Example data of the top nordics waste shipments by tonnage

"Nordic_shipment_economic_potential" is a query of the largest recorded shipments of waste in the dataset, grouped by level 2 EWC-stat code. Recycling potential indices are estimations.

"Nor_Den_Effluent_Sludge_Exp_Waste_For_Disposal.csv" is an example of ungrouping the middle_level and grouped by 6-digit LoW code, giving the full waste character detail of the dataset.
